# Intelligence Bureau Application Form

A clean and professional government application form interface built with HTML and CSS, designed for the Intelligence Bureau's Multi-Tasking Staff (MTS) recruitment process.
<img width="1919" height="1030" alt="image" src="https://github.com/user-attachments/assets/51e61284-c421-4e86-972f-c61eccee761a" />

## Features

- **Official Government Design**: Authentic government website aesthetic with proper branding
- **Responsive Form Layout**: Clean, organized form structure with proper field validation indicators
- **User-Friendly Interface**: Clear instructions and helpful notes for applicants
- **Professional Styling**: Consistent color scheme matching government website standards
- **Form Validation Ready**: Fields marked with required indicators for easy validation implementation

## Preview

The form includes sections for:
- Candidate's full name
- Parent/guardian information
- Date of birth
- Gender selection
- Contact information (email and mobile)
- Category selection (General/OBC/SC/ST/EWS)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/ib-application-form.git
```

2. Navigate to the project directory:
```bash
cd ib-application-form
```

3. Open `index.html` in your web browser:
```bash
open index.html
```

## Usage

This is a static HTML form that can be integrated with any backend system. To use it:

1. Open the HTML file in any modern web browser
2. Fill in the required fields marked with *
3. Click "Register" to submit (backend integration required)
4. Use "Reset" to clear all form fields

## Customization

### Colors
The main colors used in the design can be modified in the CSS:
- Primary Dark: `#34495e`
- Background: `#e8e8e8`
- Header Background: `#f5f5f5`
- Accent: `#27ae60`

### Form Fields
Add or modify form fields by editing the HTML structure within the `.form-section` div.
